# 心向 · iPad 安装与离线使用

1. 用 iPad 的 **Safari** 打开提供的 HTTPS 链接。
2. 打开左上角学习目录，等待下方显示 **“离线资料已就绪 · 可断网学习”**。
3. 点 Safari 的分享按钮，选择 **“添加到主屏幕”**；如果有“作为 Web App 打开”选项，保持开启。
4. 从主屏幕第一次打开“心向”时保持联网，再确认一次离线资料已就绪。
5. 此后可关闭网络，点击主屏幕图标学习。三维模型、54 个病例和四条真实 ECG 均包含在离线资料中。

横屏适合同时比较模型、投影与波形；竖屏可向下滚动。拖动旋转心脏，双指缩放；播放、逐帧和时间轴同步控制向量与波形。

首次缓存需要联网。系统清理网站数据、删除网页应用或释放缓存后，需要联网重新准备资料。外部参考链接需要联网。

这是网页应用，ZIP 是部署备份；无需将 ZIP 发到“文件”App 安装，也不需要 Windows 的 EXE。公开链接免登录，任何拿到链接的人均可访问。学习进度保留在当前设备浏览器，不上传到服务器。

模型与病例为教学近似。四条真实 ECG 保留来源和许可，VCG 明确标为 Kors 重建。
